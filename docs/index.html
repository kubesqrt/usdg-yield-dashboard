Data: protocol APIs where available (Aave V4, Maple, Jupiter, Kamino vaults, Morpho), Merkl for reward campaigns (end dates, eligibility), and DefiLlama Yields for everything else plus 90-day history. "Deposits" = total supplied, not just unborrowed cash. Refreshed automatically by a GitHub Action. APY = base (organic interest/fees) + rewards open to any on-chain depositor (incentives can end at any time; end dates shown when known). Rewards restricted to specific users (e.g. Robinhood App) are shown separately and not included in the headline APY. "Morpho Blue market" and "Kamino Vault" rows overlap with other rows (a vault's deposits sit in the markets/reserves), so they are excluded from totals to avoid double counting.
